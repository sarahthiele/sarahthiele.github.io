# sarahthiele.me

Personal academic website. Hosted on GitHub Pages.

## Files

```
index.html      — Home
about.html      — About
research.html   — Research projects
cv.html         — Curriculum vitae
contact.html    — Contact info
style.css       — All styles (one shared file)
nav.js          — Auto-injects nav + footer on every page
CNAME           — Custom domain config for GitHub Pages
photo.jpg       — Your headshot (add this yourself — see below)
cv.pdf          — Your CV PDF (optional — see cv.html comments)
```

## Setup (one-time)

### 1. Create a GitHub repo

- Go to github.com → New repository
- Name it exactly: `sarahthiele.github.io`
  (or any name, but `username.github.io` gets a free subdomain)
- Make it **Public**

### 2. Upload these files

Either drag-and-drop in the GitHub web UI, or:

```bash
git init
git add .
git commit -m "initial site"
git branch -M main
git remote add origin https://github.com/sarahthiele/sarahthiele.github.io.git
git push -u origin main
```

### 3. Enable GitHub Pages

- In the repo: Settings → Pages
- Source: **Deploy from a branch** → branch: `main`, folder: `/ (root)`
- Save

### 4. Add your custom domain

- In Settings → Pages → Custom domain: type `sarahthiele.me` → Save
- GitHub will create/verify the CNAME file automatically (it's already in this repo)

### 5. Update your domain's DNS (at your registrar)

Add these **A records** pointing to GitHub Pages:

```
185.199.108.153
185.199.109.153
185.199.110.153
185.199.111.153
```

And this **CNAME record**:
```
www  →  sarahthiele.github.io
```

DNS changes take a few minutes to a few hours. Once propagated, your site will be live at sarahthiele.me with HTTPS (GitHub handles the certificate automatically).

## Adding your photo

1. Add your headshot as `photo.jpg` in the same folder as `index.html`
2. If you want a different filename, edit the `src` in `index.html`

## Adding a CV PDF

1. Add your CV as `cv.pdf` in the same folder
2. In `cv.html`, uncomment the Download PDF button (search for `cv.pdf`)

## Editing content

Each page is a plain HTML file — edit the text directly. The nav and footer
are auto-generated by `nav.js` so you only need to update them in one place.

## Making updates later

```bash
# Edit files locally, then:
git add .
git commit -m "update research page"
git push
```

GitHub Pages will rebuild in ~30 seconds.
